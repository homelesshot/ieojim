이어짐 이용 가이드

현장에서 들은 말 한 번으로 — 예비판단부터 상담일지 초안까지 자동으로.

▶ 지금 바로 시작하기

🧭 이어짐은 위기가구를 만난 현장에서, 상황을 말하거나 입력하면 AI가 긴급복지 판단에 필요한 항목을 정리해 예비판단·지원 연계·상담일지(한글 문서)까지 한 번에 만들어 주는 도구예요.

설치도, 로그인도 필요 없어요. 링크만 열면 바로 씁니다. (상담을 저장·이어보기 하려면 회원가입만.)

3단계면 끝나요

순서대로 따라오시면 됩니다.

1

대상자 유형을 고르고, 상황을 말하거나 적어요

노숙인·쪽방·가정폭력 피해자 등 유형을 고른 뒤, 상담 상황을 그대로 전달하면 됩니다.

🎤 녹음⌨️ 텍스트 입력바로 진행도 가능
2

AI가 정리한 항목을 확인·보완해요

거주·소득·재산·건강 등을 AI가 자동으로 채워 줍니다. 비어 있거나 애매한 칸만 직접 고르고 [이전]/[다음]으로 넘기면 돼요.

자동 채움중요한 항목은 사람이 확인
3

결과와 상담일지가 자동으로 완성돼요

마지막에 [예비판단 실행]을 누르면 예비판단 → 지원 연계 안내 → 상담일지 초안이 순서대로 만들어집니다. 한글 문서(.hwpx)로 저장해 바로 쓰세요.

자주 묻는 질문

로그인을 꼭 해야 하나요?

아니요. 판단·상담일지 만들기는 로그인 없이 100% 됩니다. 상담을 저장하고 나중에 이어보려면 회원가입만 하면 돼요(좌상단 메뉴 → 로그인/회원가입).

꼭 녹음해야 하나요?

아니요. 🎤 녹음 대신 입력창에 텍스트로 적어도 되고, 상황 입력 없이 바로 단계별로 진행할 수도 있어요.

이미 채워진 내용을 고치고 싶어요.

[이전]으로 돌아가 값을 바꾸고 다시 [다음]·[예비판단 실행]을 누르면 반영됩니다. 상담일지 초안 화면에서 글을 직접 고친 뒤 [저장]을 누르면 한글 문서에도 그대로 반영돼요.

카카오톡으로 열었더니 파일이 저장이 안 돼요.

안드로이드 카톡 안에서는 저장이 막힐 수 있어요. 상단 안내의 "다른 브라우저로 열기"를 눌러 크롬·삼성인터넷 등에서 열면 됩니다.
